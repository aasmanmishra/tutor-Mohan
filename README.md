# Whiteboard Studio

A polished, responsive whiteboard application built with vanilla HTML, CSS, and JavaScript.

## Features

- Freehand pen tool
- Highlighter tool
- Eraser tool
- Lines and arrows
- Rectangles and circles
- Text tool
- Color picker
- Adjustable stroke width
- Undo and redo
- Clear board
- Toggleable grid
- Zoom controls
- Rename board
- Export board as PNG
- Keyboard shortcuts
- Responsive layout

## Keyboard Shortcuts

| Key | Action |
| --- | --- |
| `P` | Pen |
| `H` | Highlighter |
| `E` | Eraser |
| `L` | Line |
| `R` | Rectangle |
| `C` | Circle |
| `A` | Arrow |
| `T` | Text |
| `Ctrl/Cmd + Z` | Undo |
| `Ctrl/Cmd + Shift + Z` | Redo |
| `Ctrl/Cmd + Y` | Redo |
